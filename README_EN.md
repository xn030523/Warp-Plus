# Warp Plus

🇺🇸 English | [🇨🇳 简体中文](README.md)

> A desktop enhancement tool for Warp Terminal built with Tauri + React + TypeScript

**Warp Plus** is an enhancement tool designed for [Warp CLI](https://www.warp.dev/), aimed at solving the quota limitation issues of Warp AI features. With this tool, you can:

- 🚀 **Auto Account Switch** - Get and switch to a new Warp account with one click
- ♾️ **Unlimited Quota** - Continuous Warp AI usage through multi-account management
- 🔄 **Quick Switch** - Switch between multiple accounts with one click, auto-restart Warp
- 📧 **Temp Email** - Built-in temporary email for easy new account registration

No more worries about Warp AI's daily usage limits - keep your terminal AI assistant online anytime!

## ✨ Core Features

- **Warp Login Helper** - Quick login via refresh_token
- **Account Management** - Multi-account management and one-click switching
- **Quick Account Switch** - Get new accounts via card key and auto-switch
- **Temporary Email** - Auto-generate temporary email for verification codes
- **UUID Generator** - Generate and manage Warp UUID
- **MCP Manager** - Model Context Protocol rules management
