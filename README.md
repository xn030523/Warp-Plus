# Warp Plus

[🇺🇸 English](README_EN.md) | 🇨🇳 简体中文

> 基于 Tauri + React + TypeScript 构建的 Warp 终端增强工具

**Warp Plus** 是一款专为 [Warp CLI](https://www.warp.dev/) 打造的增强工具，旨在解决 Warp AI 功能的额度限制问题。通过本工具，你可以：

- 🚀 **自动换号** - 一键获取并切换到新的 Warp 账户
- ♾️ **无限额度** - 通过多账户管理实现持续使用 Warp AI
- 🔄 **快速切换** - 一键在多个账户间切换，自动重启 Warp
- 📧 **临时邮箱** - 内置临时邮箱功能，方便注册新账户

无需担心 Warp AI 的每日使用次数限制，让你的终端 AI 助手随时在线！

## ✨ 核心功能

- **Warp 登录助手** - 通过 refresh_token 快速登录
- **账户管理** - 多账户管理与一键切换
- **一键换号** - 卡密获取新账户并自动切换
- **临时邮箱** - 自动生成临时邮箱收取验证码
- **UUID 生成器** - 生成和管理 Warp UUID
- **MCP 管理器** - Model Context Protocol 规则管理
